# RepoPalette

[![CI](https://github.com/onovich/RepoPalette/actions/workflows/ci.yml/badge.svg)](https://github.com/onovich/RepoPalette/actions/workflows/ci.yml)
[![GitHub release](https://img.shields.io/github/v/release/onovich/RepoPalette?include_prereleases)](https://github.com/onovich/RepoPalette/releases)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

> Generate a validated GitHub programming-language SVG and auditable JSON from your public, owned repositories.<br/>**根据你名下的公开自有仓库，生成经过校验的 GitHub 编程语言 SVG 和可核对 JSON。**

RepoPalette is a dependency-free GitHub Action. It collects the complete public repository scope, writes ordinary files into your own repository, and keeps the last successful output if a later update fails.<br/>**RepoPalette 是一个零运行时依赖的 GitHub Action。它会完整采集公开仓库范围，把普通文件写入你自己的仓库，并在后续更新失败时保留上一份成功结果。**

## Status

The `v0.1` line is RepoPalette's first public preview. Repository collection, aggregation, filtering, validated SVG/JSON output, retries, and safe file replacement are implemented and exercised by a live Profile repository.<br/>**`v0.1` 是 RepoPalette 的首个公开预览版本。仓库采集、语言汇总、筛选、SVG/JSON 校验输出、失败重试和安全文件替换均已实现，并已在真实 Profile 仓库中运行。**

The preview renderer supports `style: bars` and `theme: light`. Redesigned layouts and additional themes remain roadmap work, so this release does not yet claim the visual differentiation planned for the finished product.<br/>**预览版渲染器支持 `style: bars` 和 `theme: light`。重新设计的布局与更多主题仍在路线图中，因此本版本暂不宣称已经实现最终产品计划中的视觉差异化。**

## Why RepoPalette

- It reads every page in the supported public repository scope instead of quietly stopping after an early page.<br/>**它会读完支持范围内的全部公开仓库分页，不会读到前几页就悄悄停止。**
- A failed update does not replace the last valid image, so a temporary API or rendering problem does not leave the Profile with a broken card.<br/>**更新失败时不会覆盖上一张有效图片，因此临时的 API 或渲染故障不会让 Profile 留下一张坏图。**
- The generated SVG and JSON stay in your repository. Displaying the image does not depend on a third-party rendering service being online.<br/>**生成的 SVG 和 JSON 保存在你自己的仓库里；展示图片时不依赖第三方实时绘图服务持续在线。**
- The JSON lists included and excluded repositories, exclusion reasons, filters, byte totals, percentages, and colors, so the result can be checked instead of merely trusted.<br/>**JSON 会列出纳入和排除的仓库、排除原因、筛选条件、字节总量、占比与颜色，让结果可以被核对，而不是只能选择相信。**
- Public repository statistics use GitHub's automatically supplied workflow token. You do not need to create, copy, or store a personal access token.<br/>**公开仓库统计使用 GitHub 自动提供的工作流令牌；你不需要创建、复制或保管个人访问令牌。**

## Quick Start

Create `.github/workflows/repopalette.yml` in the Profile repository whose name matches your GitHub username, then paste this workflow.<br/>**在与你的 GitHub 用户名同名的 Profile 仓库中创建 `.github/workflows/repopalette.yml`，然后粘贴以下工作流。**

```yaml
name: Update RepoPalette

on:
  workflow_dispatch:
  schedule:
    - cron: "17 3 * * 1"

permissions:
  contents: write

concurrency:
  group: repopalette-${{ github.ref }}
  cancel-in-progress: true

jobs:
  update:
    runs-on: ubuntu-latest
    steps:
      - name: Check out profile repository
        uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1

      - name: Generate language visual
        id: repopalette
        uses: onovich/RepoPalette@v0.1.0
        with:
          style: bars
          theme: light

      - name: Commit changed outputs
        shell: bash
        env:
          REPOPALETTE_SVG: ${{ steps.repopalette.outputs.svg-path }}
          REPOPALETTE_DATA: ${{ steps.repopalette.outputs.data-path }}
        run: |
          git add -- "$REPOPALETTE_SVG" "$REPOPALETTE_DATA"
          if git diff --cached --quiet; then
            echo "RepoPalette outputs are already current."
            exit 0
          fi

          git config user.name "github-actions[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          git commit -m "chore(profile): update RepoPalette"
          git push
```

Run the workflow once from the repository's **Actions** tab. It writes `assets/top-langs.svg` and `assets/top-langs-data.json`; later scheduled runs commit only when the statistics change.<br/>**在仓库的 `Actions` 页面手动运行一次。工作流会写入 `assets/top-langs.svg` 和 `assets/top-langs-data.json`；之后的定时任务只会在统计结果发生变化时提交。**

Embed the generated SVG in the Profile README.<br/>**在 Profile README 中嵌入生成的 SVG。**

```markdown
![GitHub languages](./assets/top-langs.svg)
```

The readable `@v0.1.0` tag is convenient for the preview. Workflows with stricter supply-chain requirements can pin RepoPalette to the full commit SHA shown by the release tag.<br/>**易读的 `@v0.1.0` 标签适合预览版快速安装；对供应链要求更严格的工作流，可以固定到该 Release 标签对应的完整提交 SHA。**

## Configuration

The two presentation inputs are deliberately small in the preview.<br/>**预览版有意只提供两个核心展示选项。**

- `style`: visual layout; currently `bars`.<br/>**`style`：视觉布局；当前支持 `bars`。**
- `theme`: color theme; currently `light`.<br/>**`theme`：颜色主题；当前支持 `light`。**

Advanced collection and output inputs are optional.<br/>**以下采集与输出高级选项均为可选。**

- `username`: account to analyze; defaults to the current repository owner.<br/>**`username`：要分析的账号；默认使用当前仓库所有者。**
- `top`: number of displayed languages, from 1 to 12; defaults to `6`.<br/>**`top`：展示的语言数量，范围为 1–12；默认 `6`。**
- `include-archived`: include archived repositories; defaults to `false`.<br/>**`include-archived`：是否纳入归档仓库；默认 `false`。**
- `exclude-repositories`: comma-separated repository names to omit.<br/>**`exclude-repositories`：需要排除的仓库名称，使用逗号分隔。**
- `exclude-languages`: comma-separated language names to omit.<br/>**`exclude-languages`：需要排除的语言名称，使用逗号分隔。**
- `title`: SVG title; defaults to `Most Used Languages`.<br/>**`title`：SVG 标题；默认 `Most Used Languages`。**
- `width`: SVG width from 320 to 800 pixels; defaults to `400`.<br/>**`width`：SVG 宽度，范围为 320–800 像素；默认 `400`。**
- `output-directory`: repository-relative output directory; defaults to `assets`.<br/>**`output-directory`：相对于仓库的输出目录；默认 `assets`。**
- `github-token`: GitHub API token; defaults to the automatic workflow token.<br/>**`github-token`：GitHub API 令牌；默认使用自动提供的工作流令牌。**

Unsupported values fail with a clear error rather than silently falling back to a different design.<br/>**不受支持的参数会明确报错，不会悄悄回退到另一种设计。**

## Outputs

- `svg-path`: absolute path to the validated SVG.<br/>**`svg-path`：经过校验的 SVG 绝对路径。**
- `data-path`: absolute path to the audit JSON.<br/>**`data-path`：审计 JSON 的绝对路径。**
- `repository-count`: number of collected public, owned repositories before filtering.<br/>**`repository-count`：筛选前采集到的公开自有仓库数量。**
- `included-repository-count`: number of repositories included after filtering.<br/>**`included-repository-count`：筛选后纳入统计的仓库数量。**
- `language-count`: number of languages in the audit data.<br/>**`language-count`：审计数据中的语言数量。**

## Data Scope

By default, RepoPalette analyzes public repositories owned by the selected account, excludes forks, and excludes archived repositories. Repository and language exclusions are applied after collection and recorded in the audit JSON.<br/>**默认情况下，RepoPalette 分析所选账号拥有的公开仓库，排除 fork，并排除归档仓库。仓库与语言排除项会在采集后应用，并记录在审计 JSON 中。**

Language shares are based on GitHub's language byte counts. They do not measure proficiency, time spent, code quality, or whether code was written by AI.<br/>**语言占比基于 GitHub 提供的语言字节数；它不衡量熟练度、投入时间、代码质量，也不判断代码是否由 AI 编写。**

## Local Development

Node.js 24 or newer is required. RepoPalette has no runtime dependencies.<br/>**本项目需要 Node.js 24 或更高版本，并且没有运行时依赖。**

```bash
npm test
npm run check
```

To generate locally, edit `repopalette.config.json`, provide an authenticated GitHub token through the environment, and run the generator.<br/>**如需在本地生成，请编辑 `repopalette.config.json`，通过环境变量提供已经认证的 GitHub 令牌，然后运行生成器。**

```bash
GITHUB_TOKEN="$(gh auth token)" npm run generate
```

## Roadmap

The next product phase covers redesigned `bars`, `orbit`, `constellation`, additional themes, a preview gallery, and an AI-assisted installation path.
